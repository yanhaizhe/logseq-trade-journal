# TradeCraft 交易工坊 — 产品设计文档

> 基于 Logseq 知识图谱的交易学习与实战一体化系统
> 版本: 1.0 | 全新设计

---

## 一、产品定位

TradeCraft 不是一个 App，而是一套以 Logseq 为数据中枢、三个专用面板为操作界面的交易工作环境。

核心理念：**学到的每一个知识点，都在交易中产生回响；每一笔交易，都反哺知识体系的成长。**

三个面板各有侧重，但共享同一份数据——你的 Logseq graph。

```
                    ┌──────────────────────┐
                    │      Logseq Graph     │
                    │    (唯一数据源)         │
                    └──────────┬───────────┘
           ┌───────────────────┼───────────────────┐
           │                   │                   │
    ┌──────▼──────┐    ┌──────▼──────┐    ┌──────▼──────┐
    │  研习室      │    │  交易台      │    │  图表工坊    │
    │  Study Room │    │ Trading Desk│    │ Chart Studio│
    │             │    │             │    │             │
    │ 理论学习     │    │ 实战交易     │    │ K线标注     │
    │ 形态识别     │    │ 风控资金     │    │ 技术分析     │
    │ 知识图谱     │    │ 复盘报表     │    │ 策略可视化   │
    └─────────────┘    └─────────────┘    └─────────────┘
```

### 2.2 数据层设计

所有业务数据存储在 Logseq 中，使用以下约定：

- 每个业务实体 = 一个 Logseq page
- 实体的字段 = block properties
- 实体间关系 = `[[]]` 双向链接
- 列表/集合 = 子 block 列表

示例 — 一笔交易在 Logseq 中的表达：

```
页面: [[T/2026-05-21/TSLA-01]]

  trade-type:: [[做多]]
  instrument:: [[TSLA]]
  timeframe:: [[1h]]
  strategy:: [[趋势跟踪/均线回踩]]

  📈 开仓
    entry-time:: 2026-05-21 10:30
    entry-price:: 248.50
    position-size:: 100 股
    position-value:: $24,850
    stop-loss:: 242.00
    risk-amount:: $650
    risk-pct:: 2.0%

  📉 平仓
    exit-time:: 2026-05-21 15:45
    exit-price:: 255.20
    pnl:: +$670
    pnl-pct:: +2.70%
    r-multiple:: 1.03R

  🧠 决策记录
    entry-bias:: 昨日突破下降趋势线，今日回踩均线获得支撑
    exit-reason:: 到达前高阻力位，主动止盈
    mistake:: [[追高冲动]] (开仓时犹豫了 2 分钟，价格多走了 0.3%)
    score:: 7/10

  🎭 情绪
    entry-mood:: [[冷静]]
    holding-mood:: [[略焦虑]]
    exit-mood:: [[满意]]

  📝 复盘
    - 这笔交易方向判断正确，入场位置可以更果断
    - 止损设置在结构低点下方合理
    - 改进点：可以用限价单替代市价单，避免滑点

  🔗 关联
    theory-source:: [[支撑与阻力]], [[趋势线画法]]
    related-trades:: [[T/2026-05-20/AAPL-03]]
```

## 三、模块一：研习室 (Study Room)

### 3.1 定位

研习室是交易理论的学习空间。它不是课程平台，而是一个让你在真实 K 线图上动手学习的工作台。

**核心交互：左侧看理论，右侧画 K 线，笔记自动沉淀到 Logseq。**

### 3.2 功能结构

```
研习室
├── 知识库
│   ├── 技术分析基础
│   │   ├── K线形态 (单根/双根/三根/复合)
│   │   ├── 趋势分析 (道氏理论/趋势线/通道)
│   │   ├── 技术指标 (MA/MACD/RSI/布林带/成交量)
│   │   └── 图形形态 (头肩/双底/三角/旗形)
│   ├── 交易心理
│   │   ├── 认知偏差
│   │   ├── 情绪管理
│   │   └── 纪律养成
│   ├── 资金管理
│   │   ├── 仓位计算
│   │   ├── 凯利公式
│   │   └── 风险敞口
│   └── 策略体系
│       ├── 趋势跟踪
│       ├── 均值回归
│       ├── 突破交易
│       └── 动量策略
├── 形态训练
│   ├── 图鉴浏览 (30+ 形态卡片)
│   ├── 实战识别 (随机图表，点击标注形态)
│   ├── 画线练习 (对比标准答案)
│   └── 测验模式 (计时计分)
└── 我的笔记
    ├── 按知识分类浏览
    ├── 知识图谱视图
    └── 学习进度统计
```

### 3.3 核心交互流

#### 3.3.1 学习一个知识点

```
用户打开研习室 → 选择「技术分析/头肩顶形态」

┌─────────────────────────────────────────────────────────┐
│  研习室 — 头肩顶形态                        [← 返回]      │
├─────────────────────────┬───────────────────────────────┤
│                         │                               │
│   📖 理论区              │   📊 K线练习区                  │
│                         │                               │
│   头肩顶是趋势反转形态，   │   ┌─────────────────────────┐ │
│   出现在上升趋势末端。     │   │                         │ │
│                         │   │   交互式 K线图             │ │
│   构成要件：              │   │   (TradingView Widget)    │ │
│   • 左肩：上涨后的高点    │   │                         │ │
│   • 头部：更高的高点      │   │   [标注工具条]           │ │
│   • 右肩：较低的高点      │   │    📏 趋势线  📐 水平线   │ │
│   • 颈线：两肩低点连线    │   │    ⬜ 矩形区  📝 文字     │ │
│                         │   │    📏 斐波那契             │ │
│   确认信号：              │   │                         │ │
│   • 跌破颈线              │   │   用户在此画颈线、        │ │
│   • 成交量放大            │   │   标注左右肩和头部         │ │
│                         │   │                         │ │
│   目标测算：              │   └─────────────────────────┘ │
│   头部到颈线的垂直距离     │                               │
│   = 最小下跌目标          │   📝 你的标注笔记:             │
│                         │   左肩高点: 1850               │
│   [标记为已掌握]          │   头部: 1920 (量缩,见顶信号)    │
│                         │   右肩: 1870 (低于左肩,确认弱)   │
│                         │   颈线: 1780 (已跌破)           │
│                         │                               │
│                         │   [💾 保存到 Logseq]           │
│                         │   [✅ 提交练习]                 │
└─────────────────────────┴───────────────────────────────┘
```

**交互细节**：

1. 左侧理论区是可滚动的 Markdown 渲染内容，从 Logseq 对应页面读取
2. 右侧 K 线图预加载了典型头肩顶案例的历史数据
3. 用户在图上标注 → 每次标注实时显示在右下方的笔记列表中
4. 点击「提交练习」→ 系统将用户的标注与标准答案对比，给出评分
5. 点击「保存到 Logseq」→ 标注笔记 + 练习结果写入 Logseq 对应页面

学习完成后，Logseq 中自动生成的笔记：

### 3.4 双视图展示

同一个知识点页面，可以在两个地方查看和编辑：

**A. 在研习室面板中看** — 美观的排版，嵌入交互式图表，适合深度学习

**B. 在 Logseq 中看** — 标准的大纲视图，适合快速浏览、建立链接、图谱导航

两者数据实时同步。在研习室编辑一段笔记 → Logseq 中对应的 block 同时更新，反之亦然。

## 四、模块二：交易台 (Trading Desk)

### 4.1 定位

交易台是实战操作面板。覆盖从选股到复盘的全流程。每一笔交易都是一条数据链路，最终在 Logseq 中形成可追溯的知识资产。

### 4.2 功能结构

```
交易台
├── 仪表盘
│   ├── 账户概览 (净值曲线/收益率/回撤)
│   ├── 持仓概览 (当前持仓/浮动盈亏)
│   ├── 今日待办 (计划交易/关注标的)
│   └── 风险预警 (仓位超标/连亏提醒)
│
├── 选股/筛选
│   ├── 自选列表 (分组管理: A股/美股/加密货币/外汇)
│   ├── 条件筛选 (技术指标筛选)
│   ├── 形态扫描 (自动检测头肩/双底/三角等)
│   └── K线快速浏览 (缩略图网格)
│
├── 交易记录
│   ├── 开仓面板 (快速录入交易参数)
│   ├── 持仓管理 (移动止损/加仓/减仓)
│   ├── 平仓面板 (记录平仓结果)
│   └── 交易日志 (按时间线浏览)
│
├── 资金与风控
│   ├── 仓位计算器 (输入止损距离 → 自动算仓位)
│   ├── 风险仪表盘 (当前总风险敞口)
│   ├── 资金曲线 (累计盈亏可视化)
│   └── 风控规则配置 (单笔最大风险/单日最大亏损等)
│
├── 复盘
│   ├── 单笔复盘 (K线回放 + 决策回顾)
│   ├── 日复盘模板
│   ├── 周/月复盘模板
│   └── 复盘检查清单
│
└── 数据报表
    ├── 交易统计 (胜率/盈亏比/夏普/最大回撤)
    ├── 按策略分布 (各策略的盈亏汇总)
    ├── 按标的分布 (各品种盈亏汇总)
    ├── 按时间分布 (日/周/月盈亏热力图)
    ├── 情绪与绩效关联分析
    └── 导出报表 (CSV/PDF)
```

## 五、模块三：图表工坊 (Chart Studio)

### 5.1 定位

图表工坊是独立的 K 线深度分析空间。当你需要不受干扰地研究图表、标注关键位置、验证策略思路时，打开图表工坊。它也是连接研习室和交易台的桥梁——你在工坊中的分析成果，可以直接注入到学习笔记或交易决策中。

### 5.2 与 TradingView 的集成

**为什么不直接嵌入 TradingView 网页？**

图表工坊使用 TradingView 的 [Advanced Chart Widget](https://www.tradingview.com/widget/advanced-chart/) 嵌入方案，但在此基础上构建了三层能力：

```
┌──────────────────────────────────────────┐
│         标注同步层 (自研)                    │
│   标注 → Logseq block 双向同步              │
├──────────────────────────────────────────┤
│         增强工具栏 (自研)                    │
│   一键保存 / 截图 / 关联笔记 / 策略标记       │
├──────────────────────────────────────────┤
│     TradingView Advanced Chart Widget     │
│   标准图表 + 内置绘图工具 + 指标               │
└──────────────────────────────────────────┘
```

**标注同步机制**：

TradingView Widget 通过 `onDrawing` 回调暴露用户的绘图操作。图表工坊监听这些事件，将标注数据序列化后写入 Logseq block properties。同时监听 Logseq 的 block 变更，反向更新图表上的标注。

```
用户在图表上画一条趋势线
  → TradingView 触发 onDrawing 事件
  → 图表工坊解析: {type: 'trendline', points: [...], text: '...'}
  → 序列化为 block property: ann-data:: {...json...}
  → 写入/更新 Logseq block

用户在 Logseq 编辑标注笔记
  → Logseq plugin 监听到 block 变更
  → 图表工坊收到通知
  → 解析 ann-data，调用 TradingView API 更新标注
```

### 5.5 标注 ↔ Logseq 双向绑定

每个标注在 Logseq 中有一个对应的 block：

```
📏 下降趋势线 (2026-03-15 → 2026-05-20)
  ann-id:: ann_tl_001
  ann-type:: [[trendline]]
  ann-points:: [[{"time": "2026-03-15", "price": 280}, {"time": "2026-05-20", "price": 240}]]
  ann-color:: #ef4444
  ann-style:: dashed
  ann-notes:: 已突破，回踩确认支撑有效。若跌破 240 则趋势延续。
  ann-tags:: [[关键趋势线]], [[支撑]]
  ann-source:: [[T/2026-05-21/TSLA-01]]
  ann-created:: 2026-05-21 10:00
```

**同步规则**：
- 在图表上创建/修改/删除标注 → 自动同步到 Logseq block
- 在 Logseq 中编辑标注笔记 → 图表上的 tooltip 同步更新
- 在 Logseq 中删除 block → 图表上的标注移除
- 在 Logseq 中添加/移除 `ann-tags` → 图表上的标注颜色/样式变化

## 八、与已有 TradingView 集成的差异点

图表工坊在 TradingView Widget 基础上新增的独有能力：

1. **标注持久化** — TradingView 图表刷新后标注丢失，图表工坊将所有标注同步到 Logseq，重新打开时完整恢复

2. **标注 ↔ 笔记双向绑定** — 在图表上的标注自动转化为 Logseq 中的结构化笔记块，在笔记中编辑内容图表同步更新

3. **跨页面关联** — 一个标注可以同时关联学习笔记、交易记录、策略文档等多条 Logseq 页面

4. **标注模板** — 预设的「学习案例」模板自动加载特定形态的 K 线图 + 预标注；「交易回放」模板展示开平仓动画

5. **多图联动** — 同一标的的不同周期图表并排显示，标注跨图同步（如在日线画趋势线，4H 图上自动投影）

6. **分析状态保存** — 完整保存当前所有图表的布局、指标、标注状态，下次一键恢复

## 十、设计原则总结

1. **Logseq 是唯一数据源** — 不在外部维护独立数据库。即使所有面板都关掉，你的全部知识、交易、标注都在 Logseq 里完整保存。

2. **双向链接是核心** — 一个知识点链接到多笔交易，一笔交易链接到知识来源和策略。链接越密，系统越强。

3. **笔记是活的** — 标注、交易、复盘都是笔记的形态，而不是冷冰冰的数据库记录。你能在任何时候编辑它们、链接它们、搜索它们。

4. **本地优先，隐私第一** — 所有数据存在本地 Logseq graph。行情数据可选接入，K线数据可本地缓存。

5. **动手优于观看** — 研习室的重点不是看视频/读文章，而是在真实图表上画线、标注、识别。学完一个形态不能只在脑中有概念，要在手上有记忆。
