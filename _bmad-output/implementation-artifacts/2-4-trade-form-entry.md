**NFRs:** NFR-3（表单提交响应 <50ms）, NFR-9（零外部网络流出）

## User Story

As a Yale,
I want 点击「录入交易」按钮弹出表单，填写买卖方向、价格、数量并勾选策略/错误标签，
So that 我能以极低摩擦记录每一笔实盘交易。

## Acceptance Criteria

**Given** 右侧 K 线已加载标的
**When** 点击「录入交易」FAB 按钮
**Then** 玻璃拟态表单卡片居中弹出，包含方向切换（买入/卖出）、价格 Numeric Input、数量 Numeric Input、策略标签复选区、错误标签复选区
**And** 方向默认「买入」，点击切换为「卖出」
**And** 价格/数量输入负值或 0 时前端校验阻止（红框+提示「价格/数量必须大于 0」）
**And** 空字段提交时表单不关闭，空字段红框+「必填项」提示
**And** 标签复选区可多选，搜索框支持模糊匹配
**And** 点击「取消」或按 Esc 关闭表单，不保存状态

## Developer Context

### 现有代码状态

1. **`src/components/KlineChart/KlineChart.tsx`**：
   - 侧边栏目前具有「自选」、「学习」、「交易」等标签页。其中「交易」标签页渲染了 `TradingNotes` 组件（该组件用于记录笔记）。
   - 当前没有任何用于全局弹窗的 `Record Trade` 表单结构，也没有触发该表单的 FAB 按钮。
   - 包含 `currentSymbol` 状态（当前加载标的）及 `currentPrice` 状态（当前标的价格，为表单价格输入提供初始推荐值）。

2. **`src/app.css`**：
   - 包含了基础的 Glassmorphism Modal 样式（如 `.tj-modal-overlay`，`.tj-modal-container` 等）。
   - 需要在该样式文件里同步追加专属于交易表单（`.tj-trade-form-overlay` 和 `.tj-trade-form-container`）的暗黑磨砂玻璃质感样式，保持一致的视觉系统与阴影发光边框。

### 需要完善的内容

#### 1. FAB 录入按钮与空状态拦截
- 需要在 K 线图容器右下角或合适位置，新增一个浮动的「录入交易」FAB 按钮（带 HSL 绿色/金色发光质感 `.tj-record-trade-fab`）。
- 若 `currentSymbol` 为空，点击 FAB 时弹窗不打开，应给出清晰的多模态错误提示（如 Toast 提示「请先在左侧输入或选择标的代码」）。

#### 2. 多模态表单控件与双向绑定
- **方向切换器**：提供「买入/卖出」滑块或高亮切换。默认「买入」呈亮绿色，点击切换为「卖出」呈亮红色。
- **输入框**：价格与数量的 Numeric Input 必须与本地 state 双向绑定。当表单打开时，价格输入框可默认填充 `currentPrice` 作为推荐初始值。
- **标签多选复选区**：
  - 策略标签预设池：使用 `TradingNotes.tsx` 已有的 `PRESET_PATTERNS` 静态数组（包含双底/双顶、看涨吞没、BOS结构破坏等）。
  - 错误标签预设池：使用 `TradingNotes.tsx` 已有的 `PRESET_PSYCHOLOGY` 静态数组（包含FOMO、报复交易、贪婪扛单等）。
  - 标签多选区顶部应支持一个文本过滤搜索框，输入拼音或中文字符时可以实时过滤备选列表，支持快速勾选，并展示已选标签的 Chip。

#### 3. 严格的前端校验与错误反馈
- 必须实现即时前端校验。若用户尝试提交空字段，或者价格/数量小于等于 0 时，阻止表单关闭。
- 触发校验错误时，对应的 Input 框边缘呈现亮红色（`border-color: var(--tj-danger)`），并且在其正下方显示警告文本（如「必填项」、「价格必须大于 0」）。

#### 4. 键盘交互（Esc & Enter）
- 表单打开时，按 `Esc` 键应当能够捕获并关闭表单，重置所有输入。
- 支持按 `Enter` 快捷提交表单（当然，前提是所有表单项均通过前端验证）。

---

## 技术约束
- 所有样式必须使用 `tj-` 前缀并遵循 kebab-case 规范。
- UI 对比度确保暗黑主题下的 WCAG AA 级别（字重与对比度足够），发光边框使用磨砂模糊背景。
- 前端验证拦截提交后不发起任何请求（零外部网络流出）。
- 必须使用 strict 严格类型安全。
