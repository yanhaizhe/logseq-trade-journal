## Overview

**Page Purpose:** 合并多账户资产、折算多币种（CNY、USD、USDT），绘制净资产（NAV）走势曲线，并提供以红绿颜色标识的日盈亏日历，帮助 Yale 宏观透视投资表现并一目了然看清每日盈亏分布。

**User Situation:** 在经历了连续交易周期后，Yale 坐在书桌前，双栏屏幕亮着。他需要了解当前各个交易账户（如 A股、美股、加密货币）在折算为本币后的总资金曲线，查看最近一个月的交易盈亏分布，并快捷进入归因标签过滤，以定位导致资金回撤的行为问题。

**Success Criteria:**
- **折算准确率**：账户对账与汇率换算达到 100% 准确（对账零误差）。
- **加载时间**：月度盈亏日历与 NAV 图表在本地数据加载下响应时间 <100ms。
- **视觉品质**：图表与卡定格在暗黑磨砂玻璃的统一美学风格中，红绿盈亏色块过渡平滑。

**Entry Points:**
- 点击 Logseq 顶部或侧边导航栏中的 `Dashboard (看板)` 按钮。
- 从交易录入成功后的画线页面点击顶部面包屑 `看板` 返回。

**Exit Points:**
- 点击指标区域下方的“标签归因过滤器 (Attribution Filter)”按钮，进入 **02.2-attribution-filter-view**。
- 点击顶部面包屑中的 `Study Lab` 进入学习探索页面。

**On-Page Interactions:**
- **NAV 悬停探针**：鼠标滑过 NAV 折线图上的任意数据点，弹出精致的玻璃悬停卡，显示当日折算本币后的总资产值、各子账户资产分项明细以及当日绝对涨跌幅。
- **日历切换**：点击盈亏日历右上角的月份或年份箭头，日历网格以淡入淡出动画（<150ms）静默加载新月份。
- **日历悬停卡**：悬停在有交易的红绿日历单元格上，显示该日“净盈亏”、“交易总笔数”、“胜率”及“最大单笔亏损”。

## Technical Notes

- **多币种本地重算**：由于 Logseq 本地优先，所有交易的原始币种（CNY/USD/USDT）必须根据对应交易日期的历史汇率换算。FastAPI 服务必须在启动时拉取并缓存在本地 sqlite 中，前端调用 `/api/calculate-nav` 接口传入 `base_currency` 在 50ms 内完成序列转换，绝不请求外网。
- **K 线与看板性能守恒**：月度盈亏日历和折线图应基于原生 HTML5 Canvas 或轻量 SVG，避免复杂图表库引起的 DOM 重绘卡顿，确保切换月份渲染时间在 50ms 以内（整页响应 <100ms）。
