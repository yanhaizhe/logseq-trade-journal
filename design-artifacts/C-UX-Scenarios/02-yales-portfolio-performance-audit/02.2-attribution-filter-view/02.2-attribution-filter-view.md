## Overview

**Page Purpose:** 允许 Yale 勾选或搜索特定策略或行为错误归因标签（如 #FOMO、#逆势抗单、#频繁交易），实时汇总该标签下造成的累计亏损、胜率、最大回撤等绩效，并在下方联动过滤显示出对应的交易记录，双击可直接定位至 Logseq 日记块，支持一键导出本地 Markdown 审计报告。

**User Situation:** 在完成月度或周度对账后，Yale 发现自己有几笔大额亏损。他想专门审计这期间因为“#FOMO 情绪”或“#频繁交易”犯下的错，了解这些坏习惯具体吃掉了多少利润，并找到对应的交易记录写下深刻的反思笔记。

**Success Criteria:**
- **筛选响应时间**：勾选标签到下方数据和表格重新过滤渲染完成的时间 <50ms。
- **定位追踪**：双击交易记录行，可在 100ms 内自动在 Logseq 侧边栏聚焦并打开对应的本地日记 (Journal Page) 块。
- **本地审计导出**：一键生成结构化的 MD 审计摘要，自动复制到剪贴板，无任何云端依赖。

**Entry Points:**
- 从 **02.1-daily-performance-dashboard** 看板点击“🔍 进入归因分类过滤器”按钮。

**Exit Points:**
- 点击顶部导航栏或面包屑中的“返回看板”按钮，返回 **02.1-daily-performance-dashboard**。
- 点击“导出审计报告 (Export Audit Report)”确认后，返回看板主页。

**On-Page Interactions:**
- **标签多选联动**：点击预设的行为标签（如 #FOMO），该标签底色高亮。允许多选，左侧汇总卡片与右侧表格实时应用 `AND`/`OR` 逻辑重新统计。
- **键盘便捷搜索**：在输入框输入标签关键字（如“抗单”），按下回车键自动选中匹配的 `#逆势抗单` 标签。
- **双击穿透**：双击过滤列表中的任意交易行，触发 Logseq API 自动在当前工作区右侧打开对应的 Logseq Block 进行深度文本编辑。

## Technical Notes

- **极速本地过滤 (Reactive Filter)**：由于所有交易元数据已加载至客户端内存，过滤动作无需向 FastAPI 重新发起 SQL 请求。JavaScript 原生的 `Array.filter` 配合 `Array.reduce` 必须在 15ms 内完成对账聚合，确保没有可感知的卡顿。
- **Logseq 侧边栏穿透接口**：双击行时，前端通过 Logseq Plugin API 的 `logseq.Editor.openInRightSidebar(uuid)` 激活 Logseq 侧边栏，将对应交易的 Markdown 笔记块展示在 Yale 视线中，极大缩减“查找-编辑”这一摩擦路径。
