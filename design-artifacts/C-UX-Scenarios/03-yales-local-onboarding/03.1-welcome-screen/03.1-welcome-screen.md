## Overview

**Page Purpose:** 展现本地依赖服务（FastAPI 后端进程、Tushare Token 状态、SQLite 本地数据库）的健康检测情况，提供清晰的状态指示，指导 Yale 快速排查本地离线问题或修改密钥配置。

**User Situation:** 第一次加载插件，或者本地服务环境由于长时间未使用发生改变（如 Tushare Token 校验失败、后台 FastAPI 端口冲突被杀）。Yale 需要在 Logseq 中查看系统自检状态，确保各服务绿色就绪，从而保障后续 K 线渲染、数据对账的无缝复盘心流体验。

**Success Criteria:**
- **自检响应速度**：进入该页面时，自检动作在 200ms 内完成，并流畅渲染状态灯。
- **环境引导清晰度**：当服务离线时，界面以醒目的黄色/红色指示，并提供可一键复制的本地终端启动脚本指令（`./start.sh`），保证配置障碍最低。
- **绝对安全**：自检行为仅与本地 `127.0.0.1:8765` 进行环回地址通信，绝不发送敏感凭证到外部公共云端。

**Entry Points:**
- 首次安装启用 Logseq Trade Journal 插件。
- 在任何页面的底部状态栏点击黄色/红色的错误状态图标跳转。

**Exit Points:**
- 点击“配置密钥”按钮进入 **03.2-token-settings-form** 面板。
- 在状态全部呈绿色时，点击“进入工作区”按钮加载复盘主页 **01.1-split-screen-kline-view**。

**On-Page Interactions:**
- **重新自检**：点击右上角“🔄 重新自检”按钮，各服务指示灯转为橙色呼吸动画，并在 150ms 内静默更新自检结果。
- **错误排查悬停卡**：当自检某项为红灯（Offline）时，鼠标悬停在红灯右侧的帮助图标上，弹出磨砂玻璃卡片显示错误代码（如 `ECONNREFUSED`）和本地排查命令（如 `lsof -i :8765`）。
- **指令一键复制**：点击悬停卡片中的启动指令，指令背景微闪（100ms），文字自动复制到剪贴板，下方显示“指令已复制”绿字。

## Technical Notes

- **本地健康环回探测**：前端使用 `fetch("http://127.0.0.1:8765/api/health")` 检测后台是否正常。必须配置 1.5s 的 timeout 超时限制。当网络连通错误（`ERR_CONNECTION_REFUSED`）触发时，判定为离线（Offline），绝不让界面卡死。
- **强制离线只读 (Offline Bypass)**：当 Tushare 离线而 FastAPI 正常时，向 FastAPI 接口 `/api/check-cache` 查询本地 sqlite 中是否有数据，若有则解锁“进入工作区”按钮，并向下游模块发送 `offline_mode = true` 的全局环境变量，通知 K 线模块从本地缓存数据库中拉取历史价格，保障离线完美运行。
