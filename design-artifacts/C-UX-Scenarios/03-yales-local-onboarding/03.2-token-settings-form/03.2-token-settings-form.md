## Overview

**Page Purpose:** 提供一个居中悬浮的暗黑磨砂玻璃模态弹窗，供 Yale 输入或更新 Tushare API Token，并通过本地后台验证接口进行实效性检测，校验成功后静默写入本地 `.env` 配置文件，以实现平滑无缝的数据同步。

**User Situation:** Yale 发现欢迎自检页中“Tushare 行情数据源”亮起红灯/黄灯，或者他的 Tushare 账户积分发生变动需要更新 Token。他点击“配置密钥”，在当前页面上弹出的干净表单中完成修改，并确保修改能立即生效。

**Success Criteria:**
- **安全可见性**：Token 输入框默认遮罩显示。支持点击右侧“眼睛”图标在一密一明文之间平滑切换（延迟 <100ms）。
- **实效性校验**：点击保存时，先调用本地 FastAPI 将 Token 提交给 Tushare 进行测试连接。校验响应时间 <2s，测试通过才允许写入本地磁盘。
- **键盘可达性**：支持 `Esc` 键放弃修改，`Tab` 键平滑在输入框与按钮间切换。

**Entry Points:**
- 从 **03.1-welcome-screen** 自检状态页点击“配置密钥”按钮。

**Exit Points:**
- 点击“保存并测试”并通过校验后，关闭弹窗，返回 **03.1-welcome-screen** 自动重算自检状态。
- 点击“取消”或按 `Esc` 键，放弃当前修改并关闭弹窗，重返 **03.1-welcome-screen**。

**On-Page Interactions:**
- **明暗文切换**：点击 Token 输入框右侧的 `settings-btn-mask-toggle` 图标，输入框 `type` 属性在 `password` 与 `text` 之间切换，图标在眼睛与闭眼图标间过渡。
- **表单即时校验**：输入框空值或少于指定字符数时，下方实时出现微弱的警示文本，且“保存并测试”按钮变为半透明不可点击状态。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| **Default** | 弹窗展现，从本地已有的 `.env` 中读取 Token 并以掩码填充。 | 输入框就绪，按钮为普通状态。 | 输入 Token，切换明文，Esc 取消。 |

## Technical Notes

- **本地存储安全性 (Local File Sync)**：由于采用 100% 本地运行，前端通过 `fetch` 将新 Token 提交给本地 FastAPI 进程。FastAPI 必须采用 Python 的 `dotenv` 模块或原生文件流修改本项目的根目录 `.env` 文件（将 `TUSHARE_TOKEN=xxx` 写入）。数据绝不通过网络传递给任何中转数据服务器。
- **物理防窥遮罩**：当弹窗重新被打开时，前端绝不在输入框中显示真实的明文 Token，必须以 `type="password"` 遮罩保护。并且在明文显示状态下，若失去焦点 (onBlur) 超过 5 秒，自动重新切换回密码掩码状态。
