## Overview

**Page Purpose:** 提供一个轻量、快捷的暗黑毛玻璃模态弹窗，供 Yale 在复盘过程中录入当前成交价格、持仓数量，并关联分类标签与归因标签，确保交易数据的结构化沉淀。

**User Situation:** Yale 在 K 线图上确认了买卖位置，需要快速补充这笔交易的价格和心理解析标签，且不希望退出当前的复盘界面以防中断思路。

**Success Criteria:**
- 模态弹窗支持 `Esc` 键一键退出，`Enter` 键智能确认写入。
- 交易方向（Buy/Sell）切换时具有微弱的绿/红自发光光晕过渡（过渡时间 <200ms）。
- 策略和错误标签列表支持键盘 Tab 导航及空格键勾选。

**Entry Points:**
- 点击分屏 K 线工作区（左侧）的“录入交易 (Record Trade)”浮动按钮。

**Exit Points:**
- 点击“确认写入 (Confirm Write)”按钮，数据静默写入 Logseq 后弹窗关闭，进入 **01.3-split-screen-kline-view**。
- 点击“取消 (Cancel)”或弹窗外部遮罩，放弃修改并返回 **01.1-split-screen-kline-view**。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | 弹窗唤醒，默认自动提取 K 线十字光标当前对应的价格与时间。 | 输入框就绪，光标默认聚焦在价格输入框。 | 输入、Tab 导航、快捷提交。 |
| Submitting | 点击“确认写入”并调用 Logseq DB API 写入属性。 | 按钮变为正在写入 Loading 动画，弹窗半透明度变暗。 | 禁用所有输入和按钮防止双重写入。 |
| Validation Error | 价格或数量为空，或者非数字提交时。 | 对应输入框边框变红（`hsl(0, 84%, 60%)`），并在输入框下方出现微弱的警示文本。 | 提示用户修正，不关闭弹窗。 |

## Technical Notes

- 弹窗必须绑定键盘 `keydown` 事件。当监听到 `Escape` 且无正在写入的 API 提交时，优雅关闭。
- 策略标签和错误标签的勾选状态需要进行双向解耦，将最终勾选项拼装为 Logseq 属性的数组格式（如 `strategies:: #突破买入, #支撑买入`）。
