## Overview

**Page Purpose:** 渲染回显已填入的成交买卖三角形标记；允许 Yale 手动进行技术画线（如支撑线、趋势通道），并一键（或通过快捷键）将当前的 K 线标的、周期、技术指标及 Canvas 画线 JSON 序列化并绑定到 Logseq 笔记块属性中，完成高精度无截图复盘。

**User Situation:** Yale 录入了买卖数据，数据已回显至 K 线。他需要在图表上画一条支撑线来分析当时买入的结构依据，并将这个视觉现场永久锁定在该 Logseq 笔记块中。

**Success Criteria:**
- 在对应的 K 线柱（Bar）上精准回显绿色向上（BUY）或红色向下（SELL）成交标记。
- 鼠标悬停（Hover）成交标记时，在 <150ms 内淡入半透明详情卡片。
- 点击“绑定状态”按钮后，K 线的关键指标（标的、周期、划线 JSON）于 100ms 内静默写入 Logseq 笔记块属性中，并在左侧编辑区出现闪烁高亮反馈。

**Entry Points:**
- 从 **01.2-trade-input-form** 成功录入数据并关闭弹窗后返回。

**Exit Points:**
- 状态绑定完成，完成本次复盘心流，退出进入主看板 **02.1-daily-performance-dashboard**。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default / Unbound | 返回主工作区，已渲染成交三角，但技术画线尚未同步保存到 Block 中时。 | 绑定按钮呈琥珀黄色（`hsl(38, 92%, 50%)`）发光，指示有未保存的视觉修改。 | 键盘画线、撤销画线、点击绑定。 |
| State Binding | 点击“绑定状态”时。 | 绑定按钮发出翠绿呼吸灯光晕，光标呈现等待状态。 | 禁用双栏拖拽，保护数据写入。 |
| Bound Success | 数据完全写入 Logseq 并校验一致后。 | 绑定按钮变更为“状态已同步”绿色标签，左栏 Block 出现绿圈 Check 指示器，底栏提示“状态已同步”。 | 允许重新画线（重置为 Unbound 状态）。 |

## Technical Notes

- 画线 Canvas 的 JSON 数组必须精简压缩（去除多余字段），以防 Logseq Markdown 单行属性字符数过长（限制在 4KB 以内），确保数据库解析性能。
- 绑定完成后，插件在本地内存中缓存该块的 Block ID 与图表状态哈希。当用户在左侧编辑器重新选择此 Block 时，读取缓存并匹配，确认无变化时，绑定按钮保持绿色同步状态。
