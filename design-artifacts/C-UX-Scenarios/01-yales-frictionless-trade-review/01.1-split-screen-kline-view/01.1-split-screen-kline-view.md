## Overview

**Page Purpose:** 建立左右拖拽分屏工作区。左侧为 Logseq 原生 Markdown/DB 笔记编辑器，右侧为 TradingView 级别的动态 K 线图表视口，辅以底部服务自检状态栏，帮助 Yale 在无截图阻力下开展双向联动复盘。

**User Situation:** 晚上收盘后，Yale 坐在书桌前，双栏屏幕亮着。他经历了一天的交易与编码，感到有些疲惫，但依然希望遵循交易纪律快速记录下当日的一笔实盘操作，并以极低的心智摩擦将笔记与 K 线状态绑定。

**Success Criteria:** 
- 左右分屏在 100% 宽度下能够以拖拽阻尼平滑调整比例。
- 右侧 K 线在输入左栏标的代码后 150ms 内完成历史行情拉取并平滑渲染。
- 底部状态栏静默以绿/黄/红呼吸灯指示本地 FastAPI 状态，无侵入式弹窗。

**Entry Points:**
- 打开 Logseq 插件侧边栏或点击主菜单 `Trading Notes` 按钮。
- 从欢迎自检状态页成功连接后自动跳转。

**Exit Points:**
- 点击工作区中央的“录入交易”浮动按钮，进入 **01.2-trade-input-form**。
- 点击顶部导航返回主看板 **02.1-daily-performance-dashboard**。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | FastAPI 正常，Tushare Token 校验通过，载入默认标的（如 BTCUSDT）均线。 | 左右布局整洁，K 线成交箭头回显正常。 | 拖拽分屏、编写笔记、点击录入。 |
| Loading | 图表正在请求 AkShare/CCXT 历史行情接口时。 | 图表正中显示极简暗金旋转 Loading 环，背景微暗。 | 输入框禁用，防止重复请求。 |
| Empty | Logseq 编辑器中无任何标的代码属性或时间戳时。 | 右侧 K 线呈现占位符图样：“请聚焦或双击笔记块以定位标的 K 线图”。 | 引导双击 K 线生成对应属性。 |
| Error | 本地 FastAPI (localhost:8765) 服务未启动或被拦截。 | 底部状态栏变红闪烁，右栏 K 线展示：“本地 FastAPI 通信离线，请使用 start.sh 脚本拉起”。 | 允许点击状态栏“重新连接”按钮。 |

## Technical Notes

- 左右拉伸必须使用 `flex-basis` 及 `min-width: 300px` 限制，防止单侧压缩至不可读。
- K 线必须调用 @klinecharts/pro 容器的 `.resize()` 接口，在拖动分屏条时节流（throttle: 30ms）重绘画布，确保画面无拉伸虚化。
- 本地 127.0.0.1:8765 通信断线时，采用优雅降级，只显示警告指示而不崩盘，保存按钮改为 Logseq 本地属性写入而不走 API 网络。
